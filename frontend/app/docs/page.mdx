# Upblit Documentation

Upblit is an open-source, AI-native cloud developer platform built for developers who want to **deploy**, **observe**, and **scale** their applications without fighting infrastructure.

## What is Upblit?

Upblit gives you:

- **One-command deployments** via the Upblit CLI — push your code, Upblit handles the rest
- **Automatic observability** — distributed traces, structured logs, and metrics with zero code changes via our SDKs
- **A full dashboard** — manage organizations, projects, applications, API keys, and view telemetry in one place
- **An AI Gateway** — upload knowledge-base documents and manage AI tenants per organization
- **Multi-language SDKs** — instrument your Express, Go, or Python app in minutes

## Core Philosophy

> **Deploy. Observe. Scale.**

Upblit is designed to replace the complexity of stitching together Heroku + Datadog + Jenkins with a single, cohesive platform that stays out of your way.
